# SketchLite MVP

A lightweight, Excalidraw-inspired drawing app MVP built with plain HTML/CSS/JavaScript.

## Features

- Freehand, line, rectangle, ellipse, and text tools
- Element selection + drag-to-move
- Stroke/fill color and stroke width controls
- Undo/redo history
- Clear canvas
- Export drawing to PNG

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
