# SketchLite React MVP (v2)

This version is rebuilt in **React** (browser-delivered React + Babel) with no build step required.

## Features

- Tools: select, freehand, line, rectangle, ellipse, text
- Drag selected shapes to reposition
- Stroke/fill color pickers and stroke width control
- Undo / redo
- Clear canvas
- Export PNG

## Run locally

```bash
python3 -m http.server 4173
```

Then open:

- `http://localhost:4173`

> Note: This React MVP loads React/ReactDOM/Babel from CDN at runtime.
